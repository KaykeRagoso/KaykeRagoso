# 💻 Infra Scripts

Scripts usados no dia a dia de suporte e infraestrutura.

## 📌 Tecnologias
- PowerShell
- Batch
- Windows Server (conceitos)

## 🚀 Scripts disponíveis

### 🔹 limpeza.bat
Limpa arquivos temporários e melhora desempenho da máquina.

### 🔹 diagnostico.ps1
Coleta:
- IP
- Ping
- Status da rede

## 🎯 Objetivo
Automatizar tarefas comuns de suporte técnico N1/N2.
